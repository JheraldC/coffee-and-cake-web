# Coffee and Cake: sitio web

Práctica realizada como trabajo de Crehana. Sitio estático construido con HTML y CSS y JavaScript.

## Contenido y capacidades

- [index.html](index.html): estructura y contenido de la página.
- [css](css): presentación visual.
- [img](img): recursos gráficos.
- [js](js): scripts de interacción, menú, navegación y otros componentes.

## Ver el proyecto

Abrir `index.html` en un navegador. También puede utilizarse un servidor local desde la raíz:

```bash
python -m http.server 8000
```

Visitar http://localhost:8000/.

## Alcance

Este repositorio demuestra maquetación y organización de recursos del frontend. No incluye un backend de comercio electrónico, procesamiento de pagos ni una demo pública verificada. La atribución del curso o los recursos originales debe conservarse cuando corresponda.
